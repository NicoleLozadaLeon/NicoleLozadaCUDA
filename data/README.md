# Map data

`equipetrol.png` is a map image of Zona Equipetrol, Santa Cruz de la Sierra, Bolivia.

- Source: OpenStreetMap (openstreetmap.org, Share -> Image tool, Standard layer).
- Format and size: PNG, 1248 x 1792 pixels, scale 1:5700.
- Bounding box (decimal degrees): west = -63.205248240852164, south = -17.77504707884483, east = -63.187351138452286, north = -17.750567044823004.
- Projection: Web Mercator (the pixel/latitude relation uses the Mercator formula).
- Visible in the image: Av. Antonio Vaca Diez (Cuarto Anillo), Av. San Martin, Av. La Salle, Av. Noel Kempff Mercado (Tercer Anillo), Av. Busch. [EDIT: add only what you can really read in the image, for example Av. Cristobal de Mendoza (Segundo Anillo) if it is visible]
- Attribution: (c) OpenStreetMap contributors, data under the ODbL licence.

## Simulated zone

The simulated zone is the east side of Av. San Martin (between San Martin and Av. La Salle), from the Cuarto Anillo to the south of the image, as agreed with the teacher. The image is not cropped; only the street network and the restaurants are restricted to that side.

## Restaurants

`restaurants_osm.csv` lists food places (restaurant, fast food, cafe, bar, ice cream) that OpenStreetMap has inside the bounding box. It was produced with Overpass Turbo and some rows were added by hand from the OpenStreetMap node pages, because the first export was incomplete. It is only the pool from which the restaurants of the simulation are chosen. Columns: latitude, longitude, name, amenity.
