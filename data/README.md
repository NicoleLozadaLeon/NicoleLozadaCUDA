# Map data

`equipetrol.jpg` is a map image of Zona Equipetrol, Santa Cruz de la Sierra, Bolivia.

- Source: OpenStreetMap (openstreetmap.org, Share -> Image tool, Standard layer).
- Format and size: JPEG, 1432 x 2767 pixels, scale 1:4050.
- Bounding box (decimal degrees): west = -63.20374411309951, south = -17.779011638450203, east = -63.18915387798629, north = -17.752162388363526.
- Projection: Web Mercator. The pixel/latitude relation uses the Mercator formula.
- Rings in the picture: Segundo Anillo = Av. Cristobal de Mendoza (bottom right corner), Tercer Anillo = Av. Noel Kempff Mercado, Cuarto Anillo = Av. Antonio Vaca Diez (top left).
- Attribution: (c) OpenStreetMap contributors, data under the ODbL licence.

`restaurants_osm.csv` lists the food places (restaurant, fast food, cafe, bar, ice cream) that OpenStreetMap has inside the bounding box. It was produced with Overpass Turbo and is only the pool from which the restaurants of the simulation are chosen. Columns: latitude, longitude, name, amenity.
